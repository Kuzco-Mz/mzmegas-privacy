TERMOS DE USO E POLÍTICA DE PRIVACIDADE - MZ MEGAS

Este documento estabelece as regras para o uso dos aplicativos e serviços da empresa ADAMO JUNIOR, focando especificamente no aplicativo "MZ Megas".

1. PRESTAÇÃO DE SERVIÇOS

O MZ Megas atua como uma ferramenta tecnológica para facilitar a compra de pacotes de dados (megas), minutos e SMS, organizando códigos USSD das operadoras locais em Moçambique e simplificando o processo de inserção de dados.

2. USO DA API DE ACESSIBILIDADE (ACCESSIBILITY SERVICE)

IMPORTANTE: O aplicativo MZ Megas utiliza a API de Serviços de Acessibilidade (AccessibilityService) do Android.

  • PORQUÊ: Exclusivamente para automatizar o preenchimento e navegação nos menus USSD.
  • COMO FUNCIONA: O app lê os ecrãs USSD durante a compra e interage com eles para poupar digitação manual.
  • PRIVACIDADE: Não recolhe, não armazena e não partilha informações pessoais ou PINs. Tudo ocorre localmente no dispositivo.

3. PRIVACIDADE E DADOS

  • COLETA: Apenas dados de preferência de pacotes configurados pelo utilizador.
  • USO: Nunca vendidos a terceiros.
  • SEGURANÇA: PINs e senhas não são processados nos nossos servidores; pagamento é manual via USSD.

4. ISENÇÃO DE RESPONSABILIDADE

  • OPERADORAS: Não nos responsabilizamos por falhas técnicas das operadoras.
  • PAGAMENTOS: O utilizador confirma manualmente cada operação; não nos responsabilizamos por deduções incorretas.

5. ACEITAÇÃO DOS TERMOS

Ao utilizar o aplicativo, o utilizador declara estar de acordo com estes termos e compreende o uso do Serviço de Acessibilidade para automação USSD.
